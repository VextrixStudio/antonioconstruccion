> **"Construyendo legados a través de la precisión técnica y la herencia artesanal."**

Antonio Construction es una plataforma digital de alta gama diseñada para proyectar la autoridad de una de las constructoras líderes en **California**. Con una estética minimalista inspirada en los estándares de diseño de Apple, Linear y Vercel, el sitio web funciona como un **Estudio de Diseño y Configuración Técnica** para proyectos residenciales y comerciales de lujo.

---

## 💎 Filosofía de Diseño

El proyecto utiliza un lenguaje visual bautizado como **"Technical Blueprint"**:
- **Dark Mode Nativo**: Uso de `zinc-950` y `#050505` para una profundidad cinematográfica.
- **Tipografía Cinematográfica**: Jerarquías masivas con interlineados cerrados (`tracking-tighter`) para transmitir fuerza y solidez.
- **Grilla de Ingeniería**: Bordes ultra-finos de `1px` y patrones de cuadrícula que evocan planos arquitectónicos.
- **Cero Fricción**: Interacciones fluidas orientadas a la conversión inmediata (SMS Directo, WhatsApp y Llamada).

---

## 🚀 Módulos Principales

### 1. Visual Design Studio (Estimate Engine v2.1)
Una herramienta interactiva donde el cliente no solo pide un presupuesto, sino que **diseña su visión**:
- **Lógica Dinámica**: El flujo de preguntas cambia según el tipo de proyecto (Remodelación vs. Construcción Nueva).
- **Pill Stack Selector**: Selección visual de materiales reales (Smooth Stucco, Oak Wood, Italian Marble).
- **ROI Engine**: Calcula automáticamente el incremento proyectado en el valor de la propiedad basado en la calidad de los materiales elegidos.

### 2. Selected Works (Portfolio)
Una galería técnica que presenta proyectos como "Logros de Ingeniería":
- **Scanner Effect**: Animaciones de línea de escaneo láser al hacer hover.
- **Metadata Técnica**: Visualización de pies cuadrados (SQFT), ubicación y sistemas de construcción aplicados.

### 3. Contact Command Center
Eliminamos los formularios largos para priorizar la velocidad:
- **Instant Messaging**: Generación dinámica de mensajes SMS/WhatsApp con el "Blueprint" del proyecto ya redactado.
- **California Coverage**: Enfoque total en el área de servicio de todo el estado con hubs principales en Los Ángeles.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14/15](https://nextjs.org/) (App Router).
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Pure Utility First).
- **Icons**: [Lucide React](https://lucide.dev/).
- **Validation**: [Zod](https://zod.dev/) para esquemas de datos técnicos.
- **Animations**: CSS nativo y transiciones de Tailwind (Optimizado para rendimiento sin librerías pesadas).

## ⚙️ Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Vextrix-Studio/antonioconstruccion.git
   ```
2. Instala las dependencias:
   ```bash
   npm install lucide-react zod clsx tailwind-merge
   ```
3. Inicia el motor de desarrollo:
   ```bash
   npm run dev
   ```
